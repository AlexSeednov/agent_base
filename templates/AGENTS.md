# Application instructions

The shared agent_base checkout is at `.agents/base/`. Before work, read
`.agents/base/instructions/entrypoint.md` and its mandatory Global rules and
Architecture files. Follow its task routing to load the relevant detailed rules.

Read `.agents/base/adapters/codex/instructions.md` for Codex-specific behavior.
Read `.agents/project.md` and, if present, `.agents/local.md` before applying
shared conventions. Project exceptions and the user's current request take
precedence. Do not assume Markdown links or Claude `@imports` were expanded
automatically; read the required files explicitly.
